🔑 Connect to GitHub

Lets this page add and edit parts and start checks. Your token is stored only in this browser.

How do I get a token? (1 minute)
  1. Open New fine-grained token on GitHub.
  2. Name it PC Price Tracker, pick an expiration (e.g. 1 year).
  3. Repository access → Only select repositories → .
  4. Permissions → Repository → Contents: Read and write and Actions: Read and write.
  5. Generate, copy, and paste it below.
